Web and Services Bug Bounty Program

Introduction

The Mozilla Bug Bounty Program is designed to encourage security research into Mozilla's websites and services and to reward those who find unique and original bugs in our web infrastructure.

Our web bug bounty program is paused. We are not accepting new submissions beginning September 11, 2026. We will reopen the program in Q1 2027. Report critical severity findings via Bugzilla or email security@mozilla.org. The program policy is detailed on our HackerOne program page.
